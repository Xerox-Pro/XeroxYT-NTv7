# 公開閲覧とCloudflare配信の修正

2026-11-15。Vercelへのデプロイは行わず、画面を既存のCloudflare API Workerから配信しました。

https://xeroxyt-ntv6-apiv1.xeroxapps.workers.dev/

- Google連携の確認失敗でホーム全体を停止せず、公開おすすめを読み込みます。個人向け取得失敗時も公開フィードへ切り替え、理由を表示します。サーバーの連携情報は削除しません。
- 個人向けShortsの取得失敗時は公開Shortsへ切り替えます。割当上限や入力エラーは切り替えで回避しません。
- SNSの再試行は、現在のフィード・検索を再取得します。
- 検索したユーザーをアプリ内で開き、取得できた公開プロフィール投稿を表示します。接続アカウント本人の投稿を他人のプロフィールに表示しません。
- SNSの連携状態取得に失敗しても公開モードへ進めます。独自おすすめは実際に取得・追加した投稿を対象にします。

API側の提供元制限は残っています。実データ確認ではInstagram公開検索が拒否され、TikTok公開おすすめは外部APIの上限に達していました。ストーリー、DM、ノート・ストーリー投稿、SNS個人向けおすすめの復旧確認はできていません。

Cloudflare配信先ではサイトへの再ログインが必要です。既存VercelドメインのCookieは移動しません。GAS版の同じ画面修正は別リポジトリに含まれ、GAS版の配信手順でリリースします。

追加更新: 公開投稿追加はTikTok・Instagramの公式共有リンクにも対応します。APIにはGAS鍵の受付を常設し、TikTok公開フィードのBrowser Run取得とInstagram公開投稿の匿名web API取得を追加しました。キーワード検索・ストーリー・ログイン後の投稿機能は制限が残っています。
