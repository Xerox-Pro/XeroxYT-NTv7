# Instagram workspace / data protection
Restores the removed app picker as a single-click selector for YouTube and Instagram only. It is not an Instagram login clone. Official Instagram handles its own authentication and safety controls. The existing password-protected API is linked as a separate experimental origin; no credential, cookie, session, DM, or media is copied into XeroxYT storage. All external links use HTTPS. The Xerox account gate still wraps the workspace.
Existing D1 data is unchanged. Passwords and session tokens should remain salted hashes/hash-only. A full application-layer encryption migration requires an inventory of primary and backup Workers and D1 schemas, per-environment secret key management, versioned authenticated encryption (AES-GCM with unique nonces and associated data), verified backups, compatibility testing, staged migration and rollback. Do not place encryption keys in source or in the database. Do not log authentication or DM contents. TLS is transport encryption, not end-to-end encryption; servers processing data must be able to read it. Existing YouTube/account history is not newly encrypted by this change.
No live Instagram API operations, Reels clone, or D1 migration are included in this change.
