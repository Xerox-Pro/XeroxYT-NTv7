# Instagram beta (same-origin)
The old social.css from commit 4fdbdd0979 is restored without the former credential/cookie-import flow. The user-supplied icon is resized for the selector. A Python endpoint runs in this Vercel project, not xeroxapp047. It requires a current Xerox account session, server-side beta tester allowlist and independent INSTAGRAM_SESSION_SECRET. No password/cookie import or public credential collection. No Instagram authentication migration is implemented; the frontend offers official Instagram while unconnected. Existing old-origin cookies cannot be moved automatically. API handlers for authorized feed/reels/stories/DM list are scaffolding until a supported authentication flow exists. D1 history encryption remains staged from the prior commit; no D1 production changes. Use HTTPS and no logging of sensitive payloads.
