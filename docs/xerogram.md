# Xerogram

XeroxYT-NTv7 のヘッダーにある ^ から開けます。Web 版の `/xerogram` が入口で、旧 `/instagram` リンクも移行先へ転送されます。GAS 版のアプリ選択からは Web 版を開きます。

## Vercel

- Python Function は `POST /api/xerogram` です。プロジェクトのサーバー専用 Secret `XEROGRAM_SECRET` に暗号学的乱数を設定します。鍵を変更すると発行済みセッションと以前の端末キャッシュは読み出せなくなります。
- Instagram パスワードと認証コードはログインリクエストにのみ含まれます。再利用する認証状態は暗号化済みの HttpOnly Cookie に入ります。Cookie の有効期限は 7 日です。ログアウト時は端末のセッションを削除し、Instagram 側のログアウトも試みます。
- API は同一オリジンの JSON リクエストを受け付け、レスポンスを共有キャッシュに保存しません。CDN の画像・動画はブラウザーが直接読み込みます。署名付き URL の期限が切れたときは更新ボタンを使います。
- フィード、検索、プロフィールなどの取得済みデータは、ブラウザーの IndexedDB にアカウント別で暗号化して保存します。アプリは期限による削除を行いません。保存できる量やブラウザーによる消去は端末に依存します。ストーリーズと通常の DM はメモリ内で再利用します。送信元本人が Xerogram で取り消した DM は本人の端末に保持します。
- ポーリング、動画中継、バックグラウンドジョブは行いません。画面遷移では取得済みデータを再利用し、取得し直す操作は更新ボタンから行います。Fluid Active CPU の日次目標は 10 分です。利用量に連動するため、達成状況は Vercel の使用量で確認します。
- Instagram の追加確認や接続制限が返った場合はアプリで表示します。ライブ配信、通話、画像・動画の投稿は未対応です。

## 開発

Python 3.13 以上で `pip install -r requirements.txt` を実行し、ローカルの環境変数に開発用の `XEROGRAM_SECRET` を設定します。

```text
python -m flask --app api.xerogram run --host 127.0.0.1 --port 5117
```

別のターミナルで `XEROGRAM_DEV_API=http://127.0.0.1:5117` を環境変数に設定し、`npm run dev` で起動します。XeroxYT 側の既存 API の設定はプロジェクトの README を参照してください。
