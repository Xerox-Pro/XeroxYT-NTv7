# Xerogram

XeroxYT-NTv7の左メニューで「ホーム」の下にある「アプリ切り替え」を開き、Xerogramを選択する。XeroxYTのログインを済ませてからInstagramアカウントを接続する。従来の `/instagram` は `/xerogram` に転送される。

## 実行環境

React画面は既存のViteビルドに遅延読み込みで組み込む。Pythonは同じVercelプロジェクトの `/api/xerogram` で実行する。InstagramのHTTP通信にはinstagrapi 3.2.22を使う。Linux向けネイティブ依存のcurl_cffiなどを使うため、Cloudflare Python Workersでの実行は採用していない。Cloudflareの既存アカウントAPIで、操作ごとにXeroxYTのログインを確認する。

Vercelの本番環境では既存の `API_BASE_URL_1`（または `API_BASE_URL`）、必要な場合は `API_SHARED_SECRET`、43文字以上のランダムな `XEROGRAM_SECRET` が必要。鍵をローテーションすると、発行済みセッションと以前の端末キャッシュが読めなくなる。鍵の値はリポジトリに置かない。

セッションは7日間有効なAES-256-GCMのHttpOnly Cookieに入れ、XeroxYTのセッションとInstagramアカウントの枠に結び付ける。パスワードは永続保存しない。1つのブラウザーで3アカウントまで接続できる。大きすぎてCookieに格納できないInstagramセッションはエラーを表示する。アプリのレート制限はFunctionインスタンス内で適用される。全インスタンス共通の制限は未実装。

## 動作範囲

| 画面 | 対応した操作 |
| --- | --- |
| ホーム・検索 | ホームフィード、アカウント・ハッシュタグ検索、検索履歴、おすすめアカウント、いいね、コメント、保存 |
| DM | 受信一覧、会話の開封時に既読送信、テキスト・写真の送信、返信、右スワイプ、リアクション、送信取消、グループ表示・作成 |
| ストーリー | 閲覧、写真投稿、いいね、閲覧済み操作、閲覧者、ハイライト、親しい友達の追加・削除 |
| リール・投稿 | 縦スワイプ、表示中の動画再生、いいね・コメント・保存、写真または写真アルバムの投稿、キャプション編集、削除 |
| その他 | プロフィール表示・編集、フォロー・フォロー解除、フォロワー・フォロー中、保存済み投稿、ノートの閲覧・投稿、アクティビティ通知 |

Vercel Functionのリクエスト上限内に収めるため、画像投稿は合計3 MB、最大6枚のJPEG・PNG・WebPに限定する。動画投稿・動画DM送信はアップロードと変換処理が未実装。DM編集とストーリーへのテキスト返信は、このバージョンで利用できる安定したラッパーを確認できていない。消えるDM、端末へのプッシュ通知、ライブ、通話、独立したおすすめ投稿の一覧は未対応。GAS版のアプリ切り替えでXerogramを選ぶと、VercelのWeb版が別タブで開く。

保存済みの投稿データやDMはアカウント別の暗号化IndexedDBから先に表示する。DMでは最新ページのIDと変更内容を照合し、履歴の範囲外にある変更はそのページを取り直したときに反映する。キャッシュ内の古いデータを含め、画面から手動で削除できる。画像・動画はブラウザーからCDNに直接アクセスし、メディア本体はブラウザーのHTTPキャッシュ設定に従う。ストーリー・ノートは期限を考慮して永続保存しない。APIには定期ポーリングを行わない。

## 検証

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -p xerogram_api_test.py
npm run lint
npm run build
```

APIテストはInstagramに通信せず、オリジン検証、XeroxYTのセッション確認、セッション復元・分離、エラー応答を検証する。
